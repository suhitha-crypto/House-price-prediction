# House Price Prediction Using Ridge Regression

## Overview
This project predicts house prices using the King County Housing dataset.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Data Preprocessing
5. Ridge Regression Model
6. Model Evaluation

## Evaluation Metrics
- R² Score
- RMSE
- MAE

## Key Features
- House age calculation
- Renovation analysis
- Log transformation
- One-hot encoding
- Feature scaling

## Results
The model successfully predicts housing prices using engineered features and regularized linear regression.
